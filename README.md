# Hospital Database

# 📌 Overview
This project demonstrates fundamental SQL operations using a Hospital Database scenario. It covers table creation, modification, renaming, and deletion strategies — essential skills for database management.

The exercises simulate real-world hospital data handling, focusing on patients’ records and how to manage them efficiently with SQL commands.

# 🚀 Challenge Breakdown
1. CREATE Table
Create a table named Patients with fields:

PatientID (Primary Key)
PatientName (VARCHAR)
Age (INT)
Gender (VARCHAR)
AdmissionDate (DATE)

2. ALTER – Add Column
Add a new column:

DoctorAssigned VARCHAR(50)

3. ALTER – Modify Column
Increase PatientName length from VARCHAR(50) → VARCHAR(100)

4. RENAME Table
Rename table Patients → Patient_Info

5. TRUNCATE vs DROP
TRUNCATE: Clears all patient records but keeps table structure.

DROP: Removes the table permanently.

# 📖 Key Learnings
CREATE: Build structured tables for hospital data.

ALTER: Adapt schema as requirements evolve.

RENAME: Maintain clarity in table naming conventions.

TRUNCATE vs DROP: Understand the difference between clearing data vs removing structure.
